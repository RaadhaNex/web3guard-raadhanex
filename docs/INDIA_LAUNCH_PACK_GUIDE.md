# Web3Guard Phase 21 — India Launch Pack Guide

## Purpose
The India Launch Pack converts stored Web3Guard readiness evidence into founder-friendly launch guidance for Indian Web3 teams.

It generates:
- Hindi/Hinglish/English founder launch checklist
- investor due-diligence summary
- hackathon demo safety pack
- founder/admin OpSec checklist
- public trust page Hindi/Hinglish summary
- UPI/Razorpay payment safety wording

## Safety rules
The pack must never claim:
- audited by Web3Guard
- certified secure
- 100% secure
- guaranteed safe
- exploit-free
- government/RBI/SEBI approved unless a real approval exists

## Correct wording
Use:
- pre-audit launch readiness snapshot
- Launch Trust Readiness only
- Not Assessed modules remain visible
- report hash proves report-payload integrity only

## Endpoints
- `GET /india-launch/status`
- `GET /india-launch/pack?user_id=...&project_id=...&mode=hinglish`

## Frontend
- `/india-launch`

## Notes
This phase does not activate payments, AI providers, wallet signing, private-key collection, or exploit automation.

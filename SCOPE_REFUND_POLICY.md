# Scope / Refund Policy

## Package scope
- Free Scan: automated preliminary findings only.
- Quick Risk Scan Report: short paid report after payment verification.
- Detailed Launch Readiness Report: expanded report across selected modules.
- Fix Suggestion Pack: safe fix direction and implementation notes.
- Manual Pre-Audit Review: manual review of agreed project surface.
- Full Launch Readiness Review: broad pre-launch review across available modules.

## Refund/scope rules
- If work has not started and the project is out of scope, the lead can be rejected or refunded manually.
- Once manual review work starts, refund depends on delivered effort, scope, and written agreement.
- Scope changes can require a new quote.
- Critical fund-risk findings should still be reviewed by qualified auditors before mainnet launch.

This is a practical MVP policy. Public commercial launch should use lawyer-reviewed terms.
